# Figma Wireframe Guide

A Figma design file is not included in this repository; use this guide to create your own wireframe and export a screenshot as `UI_Wireframes.png`.

## Frame
- Desktop frame: 1440 × 1000
- Background: light grey
- Header: dark navy with project title and a “Mini Project” label
- Summary row: four cards — Total Tasks, To Do, In Progress, Completed
- Add Task card: title, assignee, due date, status, description, Add Task button
- Task list card: search field, status filter, task rows, Edit / Next status / Delete actions

## Suggested components
- Primary button
- Secondary button
- Text input
- Dropdown
- Summary card
- Task row
- Status pill

## Export
After designing the wireframe in Figma, export the frame as PNG and add it to this repository as `UI_Wireframes.png`. Do not claim a Figma design is complete until you have created it.
