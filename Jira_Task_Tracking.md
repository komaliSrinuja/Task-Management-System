To Do → In Progress → In Review / Testing → Done

## Example test checklist
- [ ] Add a task with only a title.
- [ ] Try submitting an empty title.
- [ ] Edit a task and confirm the existing task changes.
- [ ] Cancel editing.
- [ ] Delete a task and cancel the confirmation once.
- [ ] Change status through all available states.
- [ ] Search by title and assignee.
- [ ] Filter by each status.
- [ ] Refresh the browser and check persistence.
- [ ] Test the page on a narrow/mobile viewport.

## How to recreate this in Jira
1. Create a project named “Task Management System”.
2. Create a Scrum or Kanban board.
3. Add the sample issues above as tasks/stories.
4. Use the workflow columns supported by your Jira project.
5. Replace the sample statuses with the actual progress of your work.
