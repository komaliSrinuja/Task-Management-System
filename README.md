# Task Management System

A beginner-friendly mini project demonstrating task organization, requirement documentation, Agile/Scrum planning, and project coordination.

## Features
- Create tasks with a title, assignee, due date, status, and description.
- Edit and delete tasks.
- Move tasks through To Do, In Progress, and Completed.
- Search tasks and filter by status.
- View a live task summary.
- Save tasks in browser localStorage.

## Technology
- HTML5
- CSS3
- JavaScript
- Browser localStorage
- Supporting project-management artifacts: BRD, FRD, Agile/Scrum plan, and Jira task examples

## Run the project
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add a task and try the search, filter, edit, delete, and status controls.

No server or package installation is required. Data is stored only in the current browser on the current device. Clearing browser storage may remove saved tasks.

## Project goals
- Practice documenting business and functional requirements.
- Demonstrate a simple task-management workflow.
- Show how work can be divided into backlog items and sprint tasks.
- Provide a starting point for a Figma wireframe and Jira board.

## Limitations and future improvements
This is a front-end demonstration. It does not include user authentication, a shared database, team collaboration, or a real Jira integration. Future versions could add a backend API, database, user login, and automated tests.
